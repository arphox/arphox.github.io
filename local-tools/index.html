🔒 Privacy and offline use

These tools process your input entirely on your device. Nothing you enter is uploaded or saved by the tools.

  • 🚫 No analytics or third-party resources.
  • 💻 No accounts or server-side processing.
  • 🔌 Each tool works offline once its page has loaded.

🔍 How can I verify this?

For any tool, you can check its network activity yourself:

  1. Open the tool and let the page finish loading.
  2. Open your browser's developer tools and select the Network tab.
  3. Clear the request list, then use the tool. No new network requests should appear.
  4. For an additional check, choose Offline in the Network tab (Chrome or Edge), or disconnect your device, before entering any data. The tool should still work.

The initial page load downloads the page and its assets from GitHub Pages. GitHub logs visitors' IP addresses for security purposes. Opening another page requires a connection.

These pages also use a browser-enforced Content Security Policy to block script connections and restrict resource loading. This is an extra safeguard, not a guarantee that the entire browser has no network activity.
